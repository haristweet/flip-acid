# FLIP ACID

TB-303 のフィルターをいじる時間だけを取り出したブラウザ玩具。ゲームではない。

十字キーをツマミに見立てる。押した方向にツマミをひねったことになる。
パターンを打ち込む機能は持たない。鳴っている音に対してツマミを回すだけ。

https://haristweet.github.io/flip-acid/

8BitDo FlipPad で遊ぶことを前提にしているが、キーボードでも同じように動く。

## 操作

| パッド | キーボード | 対象 |
|---|---|---|
| 十字キー 上下 | ↑↓ | cutoff |
| 十字キー 左右 | ←→ | resonance |
| L1 + 上下 | Shift + ↑↓ | env mod |
| L1 + 左右 | Shift + ←→ | decay |
| A | Z | accent（押している間） |
| B | X | slide（押している間） |
| R1 | C | 次のパターン |

斜め入力は cutoff と resonance が同時に動く。実機の両手操作はそういうものなので潰していない。

押しっぱなしで変化量が加速する。等速だと数値入力になってツマミにならない。
cutoff だけは対数（オクターブ/秒）で動く。線形だと下が死んで上が飛ぶ。

### フィルター

`BiquadFilter` の lowpass は 12dB/oct で、これでは酸っぱくならない。
1 極を 4 段重ね、4 段目を帰還に回し、出力は 3 段目から取っている。
18dB/oct でありながら 4 極ぶんの共振が乗る、という 303 の効きかたはここから出る。
帰還に `tanh` を入れてあるので、共振を上げると自己発振し、同時に低域が痩せる。

正弦波掃引で実測した値:

| resonance | DC(30Hz) | ピーク | 傾き (fc×2 → fc×4) |
|---|---|---|---|
| k=0.5 | −2.6dB | −1.6dB | −18.6 dB/oct |
| k=2.5 | −7.1dB | +7.2dB | −18.7 dB/oct |
| k=4.2 | 自己発振 | | |

画面のカーブは飾りではなく同じ伝達関数 `|H| = |p| / |p⁴ + k|` を描いている。
実測と計算は DC で 0.0dB、ピークで 0.6dB 以内に一致する。

内部は 2 倍オーバーサンプリングで走らせて 4 次で落とす。
`tanh` を 2 箇所に置いている以上、素の 48kHz で回すと折り返しが可聴域に刺さる。

帰還に 1 サンプルの遅れがあるので、カットオフを Nyquist 近くまで上げるとそこで
ループが自己発振して音が全部潰れる。実効カットオフは 16kHz で頭打ちにしてある。

### パターン

シーケンサーを捨てた以上、下敷きが固定ループだと 5 分で飽きる。
だから打ち込ませるのではなく、勝手に書き換わり続けるものを置いた。

- 16 ステップ、自然的短音階、1 拍目は常に主音
- 2 ループごとに 1〜2 ステップだけ入れ替わる（音程・ゲート・アクセント・スライドのどれか）
- R1 で丸ごと作り直す

全部変えると別の曲になってしまうので、変化量は意図的に小さくしてある。
